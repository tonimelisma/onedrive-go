# W16 Definition of Ready: a state store has its own lock

Worktree `~/src/onedrive-go-wt/state-store-lock`, branch `fix/state-store-lock`, base `af259a57`.

1. PASS **Task intent**: every engine takes a second exclusive, non-blocking `flock` on a data-dir lock file named for its state DB path, after the sync-root lock and before it opens the store, held until the store has closed; every offline open, delete, reset, rebind or rename of a drive's state DB family takes the same lock, so two writers of one store exclude each other whatever folder each syncs. `drive remove --purge` and `logout --purge` remove the config section, tell the watch, then delete the DB under the lock, and keep it (saying how to finish) when refused.
