# W24 Definition of Ready: a request's deadline reaches the token refresh and the retry wait

PASS **Task intent**: a Graph request is bounded by its own context all the way through: (a) `graph.TokenSource.Token(ctx)` and `ForceRefresh(ctx)` take the caller's context; a refresh is one sign-in request, shared by every caller that needs it while it runs, each caller waiting no longer than its own context, the refresh itself bounded by the sign-in client's timeout, and the token file written only by a refresh that finished; (b) `retry.RetryTransport` never starts a wait (Retry-After, backoff ladder, throttle gate) that would end after the request context's deadline: it returns the answer it has, at once, with no long-wait notice; (c) `status` therefore says what happened ("OneDrive had a temporary server problem" for a 503 at the budget's end) and its budget covers a token refresh.
