## request_id (question 0)
A Graph request ID is a per-request GUID; it names no account, drive, item or fixture (only Microsoft can map it), and it is what a Graph failure report needs. It is not an identifier under the rule: the masks exempt `request_id` and `RequestID`, and product logging is unchanged.
