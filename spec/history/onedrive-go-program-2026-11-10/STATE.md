## Per-PR steps (full text: `PLAN.md` lines 167 to 226)

1. `git -C ~/src/onedrive-go fetch origin`, then `go -C ~/src/onedrive-go run
   ./cmd/devtool worktree add --path ~/src/onedrive-go-wt/<name> --branch <b>`.
2. In the worktree: `go run ./cmd/devtool verify --dod --stage start`.
3. Subagent writes tests first, then the change and its docs; commits locally.
4. Review; `go test -race` on the touched packages; lint; quick.
5. Live e2e tests for a touched live path, one at a time.
6. Push, PR (body: Definition of Ready report, `Review-thread carryover`,
   `Nightly failures` when the branch holds claims).
7. `verify --dod --stage pre-merge --pr N`, then `--stage post-merge --pr N
   --worktree <path> --branch <b>`.
8. Install, status check, agent repo bookkeeping.
